# InternTrackAI

Plateforme intelligente de suivi des stagiaires développée dans le cadre du projet PFE DXC.

## Objectif du projet
InternTrackAI permet de suivre les stagiaires, leurs missions et leur progression.

## Technologies utilisées

Frontend : Angular
Backend : Spring Boot
Service IA : Python FastAPI
Base de données : PostgreSQL
CI/CD : Jenkins
Kubernetes : Minikube
GitOps : Argo CD
Observabilité : Prometheus et Grafana
Sécurité : RBAC, Semgrep, OWASP Dependency Check, Trivy
