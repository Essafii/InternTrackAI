# Stratégie CI/CD - InternTrackAI

## Objectif
Mettre en place un pipeline Jenkins pour automatiser le cycle de build, test et reporting.

## Stages du pipeline
- Checkout : récupération du code source
- Build : compilation ou construction du projet
- Test : exécution des tests automatiques
- Report : génération d'un rapport d'exécution

## Outil
Le pipeline sera exécuté avec Jenkins.
